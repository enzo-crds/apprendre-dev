JS/Tableaux : reference des methodes

Tableaux : reference complete des methodes

Les tableaux JavaScript sont des objets specialises avec un ensemble tres riche de methodes, notamment fonctionnelles (map, filter, reduce) tres utilisees en JS moderne.

Creer et acceder

bases

Methodes qui MODIFIENT le tableau original

.push(x)

Ajoute a la fin, retourne la nouvelle longueur.

.pop()

Retire et retourne le dernier element.

.unshift(x)

Ajoute au debut, retourne la nouvelle longueur.

.shift()

Retire et retourne le premier element.

.splice(debut, nb, ...items)

Retire/insere des elements a une position donnee.

.sort(fn)

Trie sur place. Sans fonction, trie par ordre alphabetique (piege sur les nombres !).

.reverse()

Inverse l'ordre sur place.

.fill(valeur)

Remplit le tableau avec une valeur.

Methodes qui NE modifient PAS l'original (retournent une copie)

.map(fn)

Nouveau tableau avec le resultat de fn appliquee a chaque element.

.filter(fn)

Nouveau tableau avec les elements pour lesquels fn retourne true.

.reduce(fn, init)

Reduit le tableau a une seule valeur (somme, objet, etc).

.slice(debut, fin)

Extrait une portion sans modifier l'original.

.concat(autre)

Fusionne avec un autre tableau, retourne un nouveau tableau.

.join(sep)

Assemble les elements en une chaine.

.flat(profondeur)

Aplati les sous-tableaux imbriques.

.flatMap(fn)

map() suivi de flat(1).

.toSorted() / .toReversed()

Versions modernes non-destructives de sort/reverse.

Methodes de recherche et test

.find(fn)

Retourne le premier element correspondant, ou undefined.

.findIndex(fn)

Retourne l'index du premier element correspondant, ou -1.

.includes(x)

true si x est present dans le tableau.

.indexOf(x)

Index de la premiere occurrence de x, ou -1.

.some(fn)

true si au moins un element verifie la condition.

.every(fn)

true si tous les elements verifient la condition.

Array.isArray(x)

Verifie si x est bien un tableau (methode statique).
