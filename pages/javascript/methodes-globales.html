JS/Reference : objets et methodes globales

Objets et methodes globales

Au-dela des types primitifs et du DOM, JavaScript fournit des objets integres pour les maths, les dates, le JSON et plus.

Math

Math.round(x)

Arrondit x a l'entier le plus proche.

Math.floor(x)

Arrondit vers le bas.

Math.ceil(x)

Arrondit vers le haut.

Math.trunc(x)

Tronque la partie decimale.

Math.abs(x)

Valeur absolue.

Math.pow(x, y)

x eleve a la puissance y.

Math.sqrt(x)

Racine carree.

Math.max(...vals) / Math.min(...vals)

Maximum / minimum d'une liste de valeurs.

Math.random()

Nombre aleatoire entre 0 (inclus) et 1 (exclu).

Math.PI / Math.E

Constantes mathematiques.

JSON

JSON.stringify(obj)

Convertit un objet JavaScript en texte JSON.

JSON.parse(texte)

Convertit du texte JSON en objet JavaScript.

Date

new Date()

Date/heure actuelle.

new Date(2026, 8, 12)

Date specifique (mois indexe a partir de 0 !).

date.getFullYear() / getMonth() / getDate()

Composants de la date.

date.getHours() / getMinutes() / getSeconds()

Composants de l'heure.

date.getTime()

Timestamp en millisecondes depuis 1970.

date.toISOString()

Format standard ISO 8601.

date.toLocaleDateString('fr-FR')

Format de date localise.

Number

Number.isInteger(x)

Verifie si x est un entier.

Number.isNaN(x)

Verifie si x est NaN (plus fiable que isNaN global).

Number.parseFloat(str) / parseInt(str)

Equivalents des fonctions globales.

x.toFixed(n)

Formate un nombre avec n decimales, retourne une chaine.

x.toString(base)

Convertit en chaine dans la base donnee (2, 16...).

Number.MAX_SAFE_INTEGER

Plus grand entier representable sans perte de precision.

Array (statique)

Array.isArray(x)

Verifie si x est un tableau.

Array.from(iterable)

Cree un tableau depuis un iterable ou un objet array-like.

Array.of(...elements)

Cree un tableau a partir des arguments donnes.

String (statique)

String.fromCharCode(code)

Cree un caractere depuis un code Unicode.

Structures avancees

new Map()

Collection cle-valeur ordonnee, cles de n'importe quel type.

new Set()

Collection de valeurs uniques.

new WeakMap() / new WeakSet()

Versions avec references faibles (garbage-collectees).

Fonctions globales

setTimeout(fn, ms)

Execute fn une fois apres ms millisecondes.

setInterval(fn, ms)

Execute fn de facon repetee toutes les ms millisecondes.

clearTimeout(id) / clearInterval(id)

Annule un timer en cours.

encodeURIComponent(str) / decodeURIComponent(str)

Encode/decode du texte pour une URL.

structuredClone(obj)

Copie profonde native d'un objet.

Map vs Object

Map

Contrairement a un objet litteral, une Map accepte des cles de n'importe quel type (pas seulement des chaines), garantit l'ordre d'insertion, et expose une propriete .size directe.
