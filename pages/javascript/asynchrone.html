Asynchrone : promesses et async/await

JavaScript est mono-thread mais gere l'asynchrone grace a une boucle d'evenements (event loop). Les Promises et async/await sont les outils modernes pour ecrire du code asynchrone lisible.

Le probleme resolu par les Promises

Une operation asynchrone (requete reseau, minuteur, lecture de fichier) ne bloque pas le reste du programme : elle "promet" un resultat futur.

Creer et utiliser une Promise

Promise de base
Etat / methodeRole
pendingEtat initial, ni resolue ni rejetee.
fulfilledResolue avec succes.
rejectedRejetee avec une erreur.
.then(fn)Execute fn quand la promesse est resolue.
.catch(fn)Execute fn si la promesse est rejetee.
.finally(fn)Execute fn dans tous les cas, succes ou echec.
Promise.resolve(x)Cree une promesse deja resolue avec la valeur x.
Promise.reject(err)Cree une promesse deja rejetee.
Promise.all(promesses)Attend que toutes les promesses soient resolues (echoue si une seule echoue).
Promise.allSettled(promesses)Attend toutes les promesses, succes ou echec, sans jamais rejeter.
Promise.race(promesses)Se resout des que la premiere promesse se termine.

async/await : la syntaxe moderne

async/await est du sucre syntaxique par-dessus les Promises : le code asynchrone se lit comme du code synchrone, plus facile a suivre.

async/await

fetch : requetes HTTP

fetch avec async/await
async function recupererDonnees() {
  try {
    const reponse = await fetch("https://api.exemple.com/donnees");
    if (!reponse.ok) {
      throw new Error(`Erreur HTTP : ${reponse.status}`);
    }
    const donnees = await reponse.json();
    console.log(donnees);
  } catch (erreur) {
    console.error("Echec de la requete :", erreur);
  }
}
