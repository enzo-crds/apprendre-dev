JS/Syntaxe et variables

Syntaxe et variables

JavaScript propose trois mots-cles pour declarer une variable, avec des regles de portee (scope) differentes.

let, const, var

declarations
Mot-clePorteeReassignable ?Recommandation
letBloc ({}) dans lequel elle est declaree.OuiUtiliser par defaut quand la valeur va changer.
constBloc ({}) dans lequel elle est declaree.Non (la reference, pas le contenu)Utiliser par defaut, c'est le choix le plus sur.
varFonction entiere (pas le bloc), sujette au "hoisting".OuiEviter en code moderne, source de bugs.
