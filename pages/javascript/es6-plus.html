ES6 et au-dela

ECMAScript 2015 (ES6) a modernise profondement JavaScript, et chaque version annuelle depuis ajoute de nouvelles fonctionnalites. Voici les plus utilisees en pratique.

Modules (import/export)

math.js
export function addition(a, b) {
  return a + b;
}

export const PI = 3.14159;

export default function principal() { /* ... */ }
app.js
import principal, { addition, PI } from "./math.js";
console.log(addition(2, 3));

Pour utiliser les modules dans le navigateur, il faut ajouter type="module" a la balise script.

Symbol et iterateurs personnalises

Symbol.iterator
const plage = {
  debut: 1,
  fin: 5,
  [Symbol.iterator]() {
    let actuel = this.debut;
    const fin = this.fin;
    return {
      next() {
        return actuel <= fin
          ? { value: actuel++, done: false }
          : { value: undefined, done: true };
      }
    };
  }
};

for (const n of plage) console.log(n);  // 1 2 3 4 5
