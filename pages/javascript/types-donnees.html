Types de donnees

JavaScript a un typage dynamique (comme Python) mais faible : il convertit souvent automatiquement les types entre eux, ce qui peut surprendre.

typeof et conversions

Valeurs "fausses" (falsy)

Ces huit valeurs sont evaluees comme false : false, 0, -0, 0n, "", null, undefined, NaN. Tout le reste, y compris "0" et [] (contrairement a Python !), est truthy.

Piege classique. En JavaScript, [] == false est true a cause de la conversion automatique, mais Boolean([]) est aussi... true ! C'est [] == false qui convertit les deux operandes differemment. Preferez toujours === pour eviter ces surprises (voir la page Operateurs).

NaN et son piege

NaN.js
console.log(0/0);          // NaN
console.log(NaN === NaN);  // false ! NaN n'est jamais egal a lui-meme
console.log(Number.isNaN(NaN)); // true : la bonne facon de tester
