JS/Le DOM

Le DOM (Document Object Model)

Le DOM est la representation en memoire de la page HTML, organisee en arbre. JavaScript peut le lire et le modifier, ce qui met a jour instantanement ce que l'utilisateur voit.

Selectionner des elements

MethodeRetourne
document.getElementById(id)Un seul element (ou null).
document.querySelector(selecteur)Le premier element correspondant au selecteur CSS (ou null).
document.querySelectorAll(selecteur)Une NodeList de tous les elements correspondants.
document.getElementsByClassName(nom)Une HTMLCollection "live" des elements ayant cette classe.
document.getElementsByTagName(tag)Une HTMLCollection "live" de toutes les balises de ce type.
querySelector est recommande. Il accepte n'importe quel selecteur CSS (".classe", "#id", "div > p"), ce qui le rend plus flexible que les methodes plus anciennes.

Lire et modifier le contenu

ProprieteRole
element.textContentTexte brut, sans interpretation HTML (le plus sur).
element.innerHTMLContenu HTML, interprete les balises (attention aux failles XSS avec du contenu utilisateur).
element.innerTextTexte visible tel qu'affiche (respecte le CSS, plus lent que textContent).
element.valueValeur d'un champ de formulaire (input, textarea, select).

Modifier attributs, classes, styles

SyntaxeRole
element.getAttribute(nom)Lit un attribut.
element.setAttribute(nom, valeur)Definit un attribut.
element.removeAttribute(nom)Supprime un attribut.
element.classList.add(classe)Ajoute une classe CSS.
element.classList.remove(classe)Retire une classe CSS.
element.classList.toggle(classe)Ajoute la classe si absente, la retire si presente.
element.classList.contains(classe)Verifie la presence d'une classe.
element.style.proprieteModifie une propriete CSS inline (camelCase : backgroundColor).
element.dataset.nomLit/ecrit un attribut data-nom.

Creer et inserer des elements

creation dynamique
const nouveauParagraphe = document.createElement("p");
nouveauParagraphe.textContent = "Ajoute par JavaScript";
nouveauParagraphe.classList.add("info");

document.body.appendChild(nouveauParagraphe);       // ajoute a la fin
document.body.prepend(nouveauParagraphe);           // ajoute au debut

const parent = document.querySelector("#conteneur");
parent.insertBefore(nouveauParagraphe, parent.firstChild);

// Retirer un element
nouveauParagraphe.remove();

Naviguer dans l'arbre DOM

ProprieteRetourne
element.parentElementL'element parent.
element.childrenLes elements enfants directs (HTMLCollection).
element.firstElementChild / lastElementChildPremier / dernier enfant.
element.nextElementSibling / previousElementSiblingElement frere suivant / precedent.
element.closest(selecteur)Remonte l'arbre jusqu'a trouver un ancetre correspondant au selecteur.
textContent vs innerHTML pour la securite. N'utilisez jamais innerHTML avec du contenu fourni par un utilisateur sans l'assainir au prealable — cela peut permettre l'injection de scripts malveillants (XSS). Preferez textContent quand vous n'avez pas besoin d'interpreter du HTML.
