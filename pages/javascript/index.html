JS/Introduction

Introduction a JavaScript

JavaScript est le langage qui rend les pages web interactives : il s'execute dans le navigateur (et aussi cote serveur avec Node.js), reagit aux actions de l'utilisateur, modifie le HTML et le CSS en temps reel, communique avec des serveurs.

Ajouter du JavaScript a une page

1. Fichier externe (recommande)
<script src="script.js" defer></script>
2. Code integre dans la page
<script>
  console.log("Bonjour");
</script>

Essayez

Bac a sable JavaScript

Ou s'execute JavaScript

  • Dans le navigateur — chaque onglet execute JS dans un environnement lie a la page (le DOM, window, document).
  • Cote serveur avec Node.js — le meme langage peut ecrire des serveurs, scripts, outils en ligne de commande.
  • Dans la console du navigateur — un excellent bac a sable pour experimenter (touche F12).

console.log : votre meilleur ami

deboguer avec console
console.log("info generale");
console.warn("avertissement");
console.error("erreur");
console.table([{a: 1}, {a: 2}]);   // affiche un tableau
