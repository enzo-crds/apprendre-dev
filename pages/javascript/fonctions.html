this : la difference cle avec les arrow functions

Point essentiel. Une fonction classique (function) a son propre this, determine par la maniere dont elle est appelee. Une fonction flechee (=>) n'a PAS son propre this : elle herite de celui du contexte englobant. C'est pourquoi les arrow functions sont tres utilisees dans les callbacks a l'interieur de methodes d'objet.
this dans les deux syntaxes

Fonctions comme valeurs

En JavaScript, les fonctions sont des "citoyens de premiere classe" : elles peuvent etre stockees dans des variables, passees en argument, retournees par d'autres fonctions.

callbacks et fonctions d'ordre superieur
function executer(callback) {
  callback();
}

executer(() => console.log("Execute !"));

// Une fonction qui retourne une fonction (closure)
function creerMultiplicateur(facteur) {
  return (x) => x * facteur;
}
const double = creerMultiplicateur(2);
console.log(double(5));  // 10
