JS/Objets

Objets

Un objet regroupe des paires cle-valeur. C'est la structure de donnees la plus fondamentale de JavaScript — meme les tableaux et fonctions sont techniquement des objets.

Object : methodes statiques utiles

Object.keys(obj)

Retourne un tableau des cles.

Object.values(obj)

Retourne un tableau des valeurs.

Object.entries(obj)

Retourne un tableau de paires [cle, valeur].

Object.fromEntries(arr)

Construit un objet a partir de paires [cle, valeur].

Object.assign(cible, ...sources)

Fusionne des objets dans la cible.

Object.freeze(obj)

Rend l'objet immuable (aucune modification possible).

Object.keys(obj).length

Nombre de proprietes (pas de .length direct sur un objet).

Copie superficielle vs profonde

copies.js
const original = { a: 1, b: { c: 2 } };

// Copie superficielle (shallow) : b reste partage !
const copie1 = { ...original };
const copie2 = Object.assign({}, original);

// Copie profonde (deep) : totalement independante
const copie3 = structuredClone(original);
