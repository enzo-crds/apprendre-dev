JS/Evenements

Evenements

Les evenements permettent a JavaScript de reagir aux actions de l'utilisateur : clic, saisie clavier, soumission de formulaire, defilement, et bien d'autres.

addEventListener

ecouter un evenement
const bouton = document.querySelector("#mon-bouton");

bouton.addEventListener("click", () => {
  console.log("Bouton clique !");
});

// Retirer un ecouteur (necessite une reference nommee, pas anonyme)
function gererClic() { console.log("clic"); }
bouton.addEventListener("click", gererClic);
bouton.removeEventListener("click", gererClic);

L'objet event

exploiter l'objet event
bouton.addEventListener("click", (event) => {
  console.log(event.target);        // l'element qui a declenche l'evenement
  console.log(event.type);          // "click"
  event.preventDefault();          // empeche le comportement par defaut (ex : suivre un lien)
  event.stopPropagation();         // empeche l'evenement de remonter aux parents
});

Categories d'evenements courants

Formulaires : empecher le rechargement

gerer une soumission
const formulaire = document.querySelector("form");

formulaire.addEventListener("submit", (event) => {
  event.preventDefault();  // empeche le rechargement de la page
  const donnees = new FormData(formulaire);
  console.log(donnees.get("email"));
});

Delegation d'evenements

Plutot que d'attacher un ecouteur a chaque element d'une liste (couteux et complique pour des elements ajoutes dynamiquement), on attache un seul ecouteur au parent et on verifie la cible :

delegation
const liste = document.querySelector("#ma-liste");

liste.addEventListener("click", (event) => {
  if (event.target.tagName === "LI") {
    console.log("Element clique :", event.target.textContent);
  }
});
// Fonctionne meme pour des <li> ajoutes APRES cette ligne

DOMContentLoaded : attendre que le HTML soit pret

demarrage sur
document.addEventListener("DOMContentLoaded", () => {
  // tout le HTML est disponible, on peut selectionner les elements en toute securite
  console.log("Page prete");
});
