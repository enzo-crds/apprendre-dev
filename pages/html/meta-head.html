HTML/Head, meta, SEO

Head, balises meta et referencement

Le <head> ne s'affiche pas, mais il pilote le comportement du navigateur, le partage sur les reseaux sociaux et le referencement (SEO).

Meta essentielles

head recommande
<meta charset="utf-8">
<meta name="viewport" content="width=device-width, initial-scale=1">
<title>Titre de la page (50-60 caracteres)</title>
<meta name="description" content="Resume de la page (150-160 caracteres)">
<link rel="canonical" href="https://exemple.fr/page">
<link rel="icon" href="favicon.ico">
<link rel="stylesheet" href="style.css">
Balise / attributRole
meta charsetEncodage des caracteres, toujours utf-8 aujourd'hui.
meta viewportAdaptation au mobile, indispensable.
meta descriptionResume affiche sous le titre dans les resultats de recherche.
meta name="robots"Indique aux moteurs s'ils doivent indexer/suivre la page (index, noindex, follow, nofollow).
meta name="author"Auteur du document.
link rel="canonical"URL de reference si le contenu existe a plusieurs adresses.
link rel="icon"Favicon affichee dans l'onglet.
link rel="stylesheet"Lie une feuille de style CSS externe.
link rel="preload"Precharge une ressource critique pour ameliorer la performance.
link rel="alternate"Version alternative du document (langue, flux RSS).
script src / defer / asyncCharge un script externe ; defer l'execute apres le parsing HTML, async des que possible sans bloquer.

Partage sur les reseaux sociaux (Open Graph)

balises Open Graph
<meta property="og:title" content="Titre pour le partage">
<meta property="og:description" content="Description pour le partage">
<meta property="og:image" content="https://exemple.fr/image.jpg">
<meta property="og:type" content="website">
<meta name="twitter:card" content="summary_large_image">

Ces balises controlent l'apercu affiche quand un lien est partage sur Facebook, LinkedIn, Twitter/X, etc.
