HTML/Formulaires

Formulaires

Les formulaires permettent de collecter des donnees de l'utilisateur : texte, choix, fichiers. C'est l'une des parties les plus riches en attributs du HTML.

Structure de base

Formulaire simple
Attribut de <form>Role
actionURL vers laquelle envoyer les donnees.
methodMethode HTTP : get (donnees dans l'URL) ou post (donnees dans le corps).
enctypeFormat d'encodage, "multipart/form-data" obligatoire pour l'envoi de fichiers.
novalidateDesactive la validation automatique du navigateur.
autocompleteActive/desactive l'auto-completion du navigateur.

Types de <input>

L'element <input> change totalement de comportement selon son attribut type :

TypeUsage
textTexte libre sur une ligne (par defaut).
passwordTexte masque par des points.
emailValide automatiquement un format d'e-mail.
numberNombre, avec fleches d'incrementation. Attributs min, max, step.
telNumero de telephone (pas de validation de format automatique).
urlValide un format d'URL.
searchChamp de recherche, avec une croix pour effacer sur certains navigateurs.
dateSelecteur de date natif.
timeSelecteur d'heure natif.
datetime-localSelecteur date + heure natif.
monthSelecteur mois/annee.
weekSelecteur de semaine.
colorSelecteur de couleur natif.
rangeCurseur (slider). Attributs min, max, step.
checkboxCase a cocher, plusieurs choix possibles.
radioBouton radio, un seul choix par groupe (meme attribut name).
fileSelection de fichier(s). Attribut accept pour filtrer, multiple pour plusieurs fichiers.
hiddenChamp invisible, transmis quand meme au serveur.
submitBouton d'envoi du formulaire.
resetBouton de reinitialisation du formulaire.
buttonBouton generique sans action native.
imageBouton d'envoi affiche comme une image.

Autres elements de formulaire

BaliseRole
<label>Etiquette d'un champ. L'attribut for doit correspondre a l'id du champ (ou le champ est imbrique dans le label).
<textarea>Zone de texte multi-lignes. Attributs rows, cols, maxlength.
<select>Liste deroulante. Attribut multiple pour selection multiple.
<option>Option dans un select. Attributs value, selected, disabled.
<optgroup>Regroupe des options sous un libelle dans un select.
<datalist>Liste de suggestions pour un input (autocompletion).
<fieldset>Regroupe visuellement des champs lies, avec un cadre.
<legend>Titre d'un fieldset.
<output>Affiche le resultat d'un calcul (souvent via JavaScript).
<progress>Barre de progression. Attributs value, max.
<meter>Jauge de valeur dans un intervalle connu (ex : niveau de disque).
<button>Bouton generique. Attribut type : submit (defaut dans un form), reset, button.

Attributs de validation

AttributRole
requiredChamp obligatoire avant l'envoi.
minlength / maxlengthLongueur minimale/maximale d'un texte.
min / maxValeur minimale/maximale (number, range, date).
stepPas d'incrementation (number, range).
patternExpression reguliere que la valeur doit respecter.
placeholderTexte d'exemple affiche quand le champ est vide.
disabledChamp desactive, non modifiable et non envoye.
readonlyChamp non modifiable mais envoye avec le formulaire.
autofocusLe champ recoit le focus au chargement de la page.
