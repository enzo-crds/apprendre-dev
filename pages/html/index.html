HTML/Introduction

Introduction au HTML

HTML (HyperText Markup Language) n'est pas un langage de programmation : c'est un langage de balisage. Il decrit la structure et le sens d'une page — ce qui est un titre, un paragraphe, une image, un lien — sans dire comment l'afficher (ca, c'est le role de CSS) ni comment la rendre interactive (ca, c'est JavaScript).

A quoi ressemble du HTML

Un document HTML est une suite d'elements. Un element est generalement compose d'une balise ouvrante, d'un contenu, et d'une balise fermante :

exemple.html
<p>Ceci est un paragraphe.</p>

Certains elements n'ont pas de contenu et donc pas de balise fermante, comme <img> ou <br>. On les appelle des elements vides.

Pourquoi apprendre HTML

Toute page web, aussi complexe soit-elle, repose au fond sur du HTML. C'est la fondation : sans structure claire, ni le style CSS ni les scripts JavaScript n'ont de support solide. Apprendre HTML en profondeur — y compris les balises rares, les attributs d'accessibilite, la structure semantique — rend vos pages plus robustes, mieux referencees et utilisables par tous, y compris avec des lecteurs d'ecran.

Comment utiliser cette reference

  • Structure d'un document — le squelette obligatoire de toute page HTML.
  • Texte et semantique — titres, paragraphes, emphase, citations.
  • Listes et tableaux — organiser des donnees.
  • Liens, images, medias — connecter et illustrer.
  • Formulaires — collecter des donnees utilisateur.
  • Reference : toutes les balises — la liste complete, classee par categorie.
  • Attributs globaux et attributs evenements — ce qui s'applique a (presque) toutes les balises.
  • Head, meta, SEO — les informations invisibles mais essentielles.
  • Accessibilite — rendre vos pages utilisables par tous.
