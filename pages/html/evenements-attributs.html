HTML/Attributs evenements

Attributs evenements HTML

HTML permet de brancher du JavaScript directement sur un element via des attributs "on...". En pratique, on prefere souvent addEventListener en JS moderne, mais ces attributs restent valides et utiles a connaitre.

evenement en ligne

Souris

AttributSe declenche quand...
onclickl'element est clique.
ondblclickl'element est double-clique.
onmousedownle bouton de la souris est enfonce.
onmouseuple bouton de la souris est relache.
onmouseoverle curseur entre sur l'element.
onmouseoutle curseur quitte l'element.
onmousemovele curseur bouge sur l'element.
oncontextmenule clic droit est effectue.
onwheella molette de la souris est utilisee.

Clavier

AttributSe declenche quand...
onkeydownune touche est enfoncee.
onkeyupune touche est relachee.
onkeypressune touche generant un caractere est pressee (obsolete, preferer keydown).

Formulaire

AttributSe declenche quand...
onsubmitle formulaire est soumis.
onresetle formulaire est reinitialise.
onchangela valeur d'un champ change et perd le focus.
oninputla valeur d'un champ change, a chaque frappe.
onfocusl'element recoit le focus.
onblurl'element perd le focus.
oninvalidun champ echoue a la validation native.
onselectdu texte est selectionne dans un champ.

Fenetre et document

AttributSe declenche quand...
onloadla page (ou une ressource comme une image) a fini de charger.
onunloadl'utilisateur quitte la page.
onresizela fenetre est redimensionnee.
onscrollun element ou la page defile.
oncopy / oncut / onpasteune action de presse-papier est effectuee.

Media (audio/video)

AttributSe declenche quand...
onplayla lecture demarre.
onpausela lecture est mise en pause.
onendedla lecture atteint la fin.
ontimeupdatela position de lecture change.
onvolumechangele volume est modifie.
Bonne pratique moderne. En JavaScript, preferez element.addEventListener('click', fn) aux attributs onclick en ligne : cela separe structure (HTML) et comportement (JS), et permet plusieurs ecouteurs sur le meme evenement. Voir la page Evenements du chapitre JavaScript.
