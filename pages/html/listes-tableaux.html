HTML/Listes et tableaux

Listes et tableaux

Deux facons fondamentales d'organiser de l'information en HTML : les listes pour des sequences ou collections, les tableaux pour des donnees tabulaires.

Listes non ordonnees

<ul> — liste a puces

Listes ordonnees

<ol> — liste numerotee
BaliseRole
<ul>Liste non ordonnee (puces).
<ol>Liste ordonnee (numeros). Attributs : start, reversed, type (1, A, a, I, i).
<li>Element de liste, dans ul ou ol. Attribut value pour ol.
<dl>Liste de description (paires terme/definition).
<dt>Terme a definir, dans dl.
<dd>Definition du terme, dans dl.

Liste de description

exemple.html
<dl>
  <dt>HTML</dt>
  <dd>Langage de structuration de pages web.</dd>
  <dt>CSS</dt>
  <dd>Langage de mise en forme visuelle.</dd>
</dl>

Tableaux

Un tableau HTML complet utilise plusieurs balises complementaires pour rester accessible :

Tableau complet
BaliseRole
<table>Conteneur du tableau.
<caption>Legende/titre du tableau.
<thead>Groupe des lignes d'en-tete.
<tbody>Groupe des lignes de donnees.
<tfoot>Groupe des lignes de pied (totaux, resumes).
<tr>Ligne du tableau.
<th>Cellule d'en-tete (gras, centre par defaut). Attribut scope="col" ou "row" pour l'accessibilite.
<td>Cellule de donnee standard.
<colgroup> / <col>Definit des styles s'appliquant a des colonnes entieres.

Fusionner des cellules

colspan et rowspan
<td colspan="2">Fusionne 2 colonnes</td>
<td rowspan="3">Fusionne 3 lignes</td>
Piege frequent. Ne jamais utiliser un tableau pour la mise en page generale d'une page (positionner un menu, une sidebar). Les tableaux sont reserves aux donnees tabulaires ; pour la mise en page, utilisez CSS (Flexbox ou Grid).
