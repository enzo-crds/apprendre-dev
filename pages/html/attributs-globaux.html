HTML/Attributs globaux

Attributs globaux

Ces attributs peuvent s'appliquer a presque toutes les balises HTML, quel que soit leur type.

AttributRole
idIdentifiant unique dans la page, utilise pour cibler l'element en CSS, JS ou via une ancre (#id).
classUne ou plusieurs classes separees par des espaces, pour cibler l'element en CSS ou JS.
styleCSS applique directement a l'element (a utiliser avec parcimonie).
titleTexte d'info-bulle affiche au survol.
langLangue du contenu de l'element (utile si differente de la page).
dirSens d'ecriture : ltr (gauche a droite), rtl (droite a gauche), auto.
hiddenMasque completement l'element (equivalent display:none).
tabindexOrdre de tabulation clavier. 0 = ordre naturel, -1 = focusable en JS seulement, positif = ordre personnalise (deconseille).
contenteditableRend le contenu de l'element modifiable directement dans la page.
draggableAutorise l'element a etre deplace via l'API drag and drop.
spellcheckActive/desactive la verification orthographique du navigateur.
translateIndique si le contenu doit etre traduit par des outils automatiques.
data-*Attribut personnalise pour stocker des donnees, lisible via JavaScript (dataset).
accesskeyRaccourci clavier pour activer/focaliser l'element.
autocapitalizeComportement de capitalisation automatique sur mobile.
autofocusDonne le focus a l'element au chargement de la page.
inertRend l'element et ses enfants non interactifs et ignores par les technologies d'assistance.
roleRole ARIA explicite, pour l'accessibilite (voir la page dediee).
aria-*Ensemble d'attributs d'accessibilite (aria-label, aria-hidden, etc.).
slotAssigne l'element a un emplacement nomme dans un Web Component.
partExpose l'element au style externe depuis un Web Component (::part).

data-* en pratique

exemple.html
<div data-user-id="42" data-role="admin">Marie</div>

// En JavaScript :
element.dataset.userId   // "42"
element.dataset.role     // "admin"
