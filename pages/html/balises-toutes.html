HTML/Reference : toutes les balises

Reference complete des balises HTML

La liste exhaustive des elements HTML5, classes par categorie. Utilisez Ctrl+F (ou Cmd+F) pour chercher une balise precise.

Racine et metadonnees

<html>

Element racine du document.

<head>

Conteneur des metadonnees, invisible.

<title>

Titre affiche dans l'onglet du navigateur.

<base>

Definit l'URL de base pour tous les liens relatifs de la page.

<link>

Lie une ressource externe, typiquement une feuille de style CSS.

<meta>

Metadonnee : encodage, description, viewport, reseaux sociaux.

<style>

Feuille de style CSS integree dans le document.

<script>

Code JavaScript integre ou lie.

<noscript>

Contenu affiche si JavaScript est desactive.

Sections

<body>

Contenu visible du document.

<header>

En-tete d'une page ou d'une section.

<nav>

Bloc de liens de navigation.

<main>

Contenu principal, unique par page.

<article>

Contenu autonome et distribuable.

<section>

Regroupement thematique de contenu.

<aside>

Contenu annexe, lie mais separe du flux principal.

<footer>

Pied de page ou de section.

<address>

Coordonnees de contact pour l'auteur du document.

<h1>

Titre de niveau 1, le plus important.

<h2>

Titre de niveau 2.

<h3>

Titre de niveau 3.

<h4>

Titre de niveau 4.

<h5>

Titre de niveau 5.

<h6>

Titre de niveau 6, le moins important.

<hgroup>

Regroupe un titre et ses sous-titres associes.

Contenu texte

<p>

Paragraphe.

<hr>

Separateur thematique horizontal.

<pre>

Texte preformate (respecte espaces et sauts de ligne).

<blockquote>

Citation longue en bloc.

<ol>

Liste ordonnee (numerotee).

<ul>

Liste non ordonnee (a puces).

<li>

Element d'une liste ol ou ul.

<dl>

Liste de description (termes/definitions).

<dt>

Terme d'une liste de description.

<dd>

Definition d'un terme.

<figure>

Regroupe un contenu illustratif et sa legende.

<figcaption>

Legende d'un figure.

<div>

Conteneur generique en bloc, sans signification propre.

Texte en ligne (inline)

<a>

Lien hypertexte.

<em>

Emphase (italique semantique).

<strong>

Importance forte (gras semantique).

<small>

Texte de petite taille, mentions annexes.

<s>

Texte qui n'est plus exact ou pertinent (barre).

<cite>

Titre d'une oeuvre citee.

<q>

Citation courte en ligne.

<dfn>

Terme defini pour la premiere fois.

<abbr>

Abreviation ou acronyme.

<ruby>

Annotation phonetique (utilisee pour l'asiatique).

<rt>

Texte d'annotation dans un ruby.

<rp>

Parentheses de secours pour ruby.

<data>

Associe un contenu a une valeur exploitable par machine.

<time>

Date ou heure, lisible par une machine.

<code>

Extrait de code informatique.

<var>

Variable dans une expression mathematique ou de programmation.

<samp>

Sortie d'un programme informatique.

<kbd>

Saisie utilisateur, touche de clavier.

<sub>

Indice.

<sup>

Exposant.

<i>

Texte en italique sans signification particuliere.

<b>

Texte en gras sans signification particuliere.

<u>

Texte souligne (annotation non textuelle).

<mark>

Texte surligne, pertinent dans le contexte.

<bdi>

Isole un texte pouvant avoir une direction d'ecriture differente.

<bdo>

Force la direction d'ecriture du texte (gauche-a-droite ou inverse).

<span>

Conteneur generique en ligne, sans signification propre.

<br>

Saut de ligne force.

<wbr>

Point de coupure optionnel dans un mot long.

Modifications de document

<ins>

Contenu insere/ajoute par rapport a une version anterieure.

<del>

Contenu supprime par rapport a une version anterieure.

Contenu embarque et multimedia

<img>

Image.

<iframe>

Cadre integrant un autre document HTML.

<embed>

Point d'integration pour du contenu externe (plugin).

<object>

Integre une ressource externe avec contenu de secours.

<picture>

Conteneur pour plusieurs sources d'image responsive.

<source>

Source alternative pour picture, audio ou video.

<video>

Lecteur video.

<audio>

Lecteur audio.

<track>

Piste de sous-titres ou legendes pour media.

<map>

Definit une image map cliquable.

<area>

Zone cliquable dans une image map.

Contenu SVG et Canvas

<svg>

Graphique vectoriel.

<canvas>

Surface de dessin pilotee par script.

Scripting avance

<template>

Contenu HTML inerte, clonable via JavaScript.

<slot>

Emplacement pour du contenu dans un Web Component.

Tableaux

<table>

Tableau de donnees.

<caption>

Legende du tableau.

<colgroup>

Regroupe des colonnes pour un style commun.

<col>

Definit les proprietes d'une colonne.

<tbody>

Corps du tableau, groupe de lignes de donnees.

<thead>

En-tete du tableau.

<tfoot>

Pied du tableau.

<tr>

Ligne de tableau.

<td>

Cellule de donnee.

<th>

Cellule d'en-tete.

Formulaires

<form>

Formulaire de saisie.

<label>

Etiquette associee a un champ.

<input>

Champ de saisie polyvalent (texte, case, fichier, etc.).

<button>

Bouton cliquable.

<select>

Liste deroulante.

<datalist>

Liste de suggestions pour un input.

<optgroup>

Regroupe des options dans un select.

<option>

Option dans un select ou datalist.

<textarea>

Zone de texte multi-lignes.

<output>

Resultat d'un calcul.

<progress>

Barre de progression.

<meter>

Jauge dans un intervalle connu.

<fieldset>

Regroupe des champs lies.

<legend>

Titre d'un fieldset.

Elements interactifs

<details>

Widget divulguant/masquant du contenu au clic.

<summary>

Resume visible d'un details, sert de declencheur.

<dialog>

Boite de dialogue native (modale ou non).

Contenu web components

<slot>

Point d'insertion de contenu dans un composant personnalise.

Balises obsoletes non listees. Des balises comme <center>, <font>, <marquee> ou <frame> ont existe mais sont depreciees : leur usage est remplace par CSS. Elles ne sont pas incluses ici volontairement.
