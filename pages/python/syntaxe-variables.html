Syntaxe et variables

Une variable est un nom qui pointe vers une valeur en memoire. En Python, pas besoin de declarer le type : il est deduit automatiquement.

Assignation

Variables

Regles de nommage

RegleDetail
Caracteres autorisesLettres, chiffres, underscore (_). Ne peut pas commencer par un chiffre.
Sensible a la casseage et Age sont deux variables differentes.
Conventionsnake_case pour les variables et fonctions (mon_nom_de_variable).
Mots reservesImpossible d'utiliser if, for, class, etc. comme nom de variable.
ConstantesPar convention, en MAJUSCULES (PI = 3.14159), meme si Python ne les protege pas reellement.

f-strings : formater du texte

f-strings

Les f-strings (prefixe f avant les guillemets) permettent d'inserer directement des variables et expressions dans du texte grace aux accolades {}. C'est la methode de formatage recommandee en Python moderne.
