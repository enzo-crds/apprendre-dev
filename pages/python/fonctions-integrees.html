PY/Reference : fonctions integrees

Reference des fonctions integrees (builtins)

Ces fonctions sont disponibles partout en Python sans aucun import. Elles forment le coeur du langage.

Entree/sortie

print(*args, sep, end)

Affiche du texte dans la console.

input(prompt)

Lit une ligne saisie au clavier (retourne une str).

open(fichier, mode)

Ouvre un fichier (voir la page Fichiers).

Types et conversions

int(x)

Convertit en entier.

float(x)

Convertit en nombre a virgule flottante.

str(x)

Convertit en chaine de caracteres.

bool(x)

Convertit en booleen.

list(iterable)

Convertit en liste.

tuple(iterable)

Convertit en tuple.

dict(...)

Cree un dictionnaire.

set(iterable)

Convertit en ensemble (elimine les doublons).

frozenset(iterable)

Set immuable.

bytes(x) / bytearray(x)

Convertit en sequence d'octets (im)mutable.

complex(reel, imag)

Cree un nombre complexe.

type(x)

Retourne le type de x.

isinstance(x, type)

Verifie si x est une instance de type.

Nombres et maths

abs(x)

Valeur absolue.

round(x, n)

Arrondit x a n decimales.

pow(x, y)

x a la puissance y.

divmod(a, b)

Retourne (quotient, reste) sous forme de tuple.

sum(iterable)

Somme des elements.

min(iterable)

Plus petite valeur.

max(iterable)

Plus grande valeur.

Sequences et iteration

len(x)

Nombre d'elements de x.

range(debut, fin, pas)

Genere une sequence de nombres.

enumerate(iterable)

Ajoute un index a chaque element d'un iterable.

zip(*iterables)

Combine plusieurs iterables element par element.

sorted(iterable, key, reverse)

Retourne une nouvelle liste triee.

reversed(sequence)

Retourne un iterateur inverse.

map(fonction, iterable)

Applique une fonction a chaque element.

filter(fonction, iterable)

Garde les elements pour lesquels la fonction retourne True.

all(iterable)

True si tous les elements sont vrais.

any(iterable)

True si au moins un element est vrai.

iter(objet)

Cree un iterateur a partir d'un iterable.

next(iterateur)

Recupere l'element suivant d'un iterateur.

Objets et classes

object()

Cree un objet de base.

super()

Acces a la classe parente dans une classe fille.

property()

Cree une propriete calculee dans une classe.

hasattr(objet, nom)

Verifie si l'objet possede cet attribut.

getattr(objet, nom, defaut)

Recupere un attribut par son nom (chaine).

setattr(objet, nom, valeur)

Definit un attribut par son nom.

delattr(objet, nom)

Supprime un attribut.

isinstance(x, Classe)

Verifie l'appartenance a une classe.

issubclass(Classe1, Classe2)

Verifie une relation d'heritage.

callable(x)

Verifie si x peut etre appele comme une fonction.

vars(objet)

Retourne le dictionnaire d'attributs de l'objet.

dir(objet)

Liste tous les attributs et methodes disponibles.

id(objet)

Identifiant unique de l'objet en memoire.

Fonctionnel

lambda

Cree une fonction anonyme d'une seule expression.

eval(expression)

Evalue une expression Python depuis une chaine (a utiliser avec prudence).

exec(code)

Execute du code Python depuis une chaine (a utiliser avec prudence).

Representation et formatage

repr(x)

Representation textuelle non ambigue, utile pour deboguer.

format(valeur, spec)

Formate une valeur selon une specification.

hex(x) / oct(x) / bin(x)

Convertit un entier en chaine hexadecimale/octale/binaire.

chr(n)

Retourne le caractere Unicode correspondant au code n.

ord(c)

Retourne le code Unicode du caractere c.

ascii(x)

Comme repr(), mais echappe les caracteres non-ASCII.

Introspection et divers

help(objet)

Affiche la documentation d'un objet ou d'une fonction.

globals() / locals()

Retourne les variables globales / locales sous forme de dict.

hash(x)

Retourne le hash de x (utilise pour les cles de dict/set).

input()

Lit une entree utilisateur.

__import__(nom)

Version bas niveau de l'instruction import.
