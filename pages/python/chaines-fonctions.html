PY/Fonctions sur les chaines

Chaines de caracteres : reference des methodes

Les chaines de caracteres (str) sont immuables en Python : chaque methode retourne une nouvelle chaine plutot que de modifier l'originale.

Recherche et test

.find(sous)

Index de la premiere occurrence, ou -1 si absente.

.index(sous)

Comme find, mais leve une erreur si absente.

.count(sous)

Nombre d'occurrences de sous.

.startswith(pref)

True si la chaine commence par pref.

.endswith(suff)

True si la chaine se termine par suff.

.isdigit()

True si tous les caracteres sont des chiffres.

.isalpha()

True si tous les caracteres sont des lettres.

.isalnum()

True si tous les caracteres sont alphanumeriques.

.isspace()

True si tous les caracteres sont des espaces.

.isupper() / .islower()

True si tout est en majuscule / minuscule.

Transformation

.upper()

Convertit en majuscules.

.lower()

Convertit en minuscules.

.capitalize()

Majuscule en premiere lettre seulement.

.title()

Majuscule au debut de chaque mot.

.strip()

Retire les espaces (ou caracteres donnes) en debut et fin.

.lstrip() / .rstrip()

Retire uniquement a gauche / a droite.

.replace(a, b)

Remplace toutes les occurrences de a par b.

.split(sep)

Decoupe la chaine en liste selon le separateur (espace par defaut).

.splitlines()

Decoupe selon les retours a la ligne.

.join(iterable)

Assemble une liste de chaines avec ce separateur.

.zfill(n)

Complete a gauche avec des zeros jusqu'a la longueur n.

.center(n) / .ljust(n) / .rjust(n)

Aligne/complete la chaine sur une largeur n.

.format(...)

Ancien style de formatage (predecesseur des f-strings).

.encode()

Convertit la chaine en objet bytes.
