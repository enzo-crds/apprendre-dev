Compréhensions de liste

Une facon concise et tres pythonique de creer une liste a partir d'une boucle :

list comprehension

match / case (Python 3.10+)

structural pattern matching
statut = 404

match statut:
    case 200:
        print("OK")
    case 404:
        print("Non trouve")
    case 500 | 503:
        print("Erreur serveur")
    case _:
        print("Statut inconnu")
