PY/Fichiers et contexte (with)

Fichiers et gestionnaires de contexte

Python permet de lire et ecrire des fichiers facilement, avec un mecanisme (with) qui garantit leur fermeture propre meme en cas d'erreur.

Ouvrir un fichier avec with

lecture.py
with open("donnees.txt", "r", encoding="utf-8") as f:
    contenu = f.read()
    print(contenu)
# le fichier est automatiquement ferme ici, meme si une erreur survient

Sans with, il faudrait appeler manuellement f.close(), avec le risque d'oublier de le faire si une exception survient avant. with est un gestionnaire de contexte qui garantit le nettoyage.

Modes d'ouverture

ModeEffet
"r"Lecture (par defaut). Erreur si le fichier n'existe pas.
"w"Ecriture, ecrase le contenu existant (ou cree le fichier).
"a"Ajout a la fin du fichier existant (ou le cree).
"x"Creation exclusive, erreur si le fichier existe deja.
"b"Mode binaire, a combiner avec les precedents (ex : "rb").
"r+"Lecture et ecriture.

Methodes de lecture

MethodeRole
f.read()Lit tout le fichier d'un coup, retourne une chaine.
f.readline()Lit une seule ligne.
f.readlines()Lit toutes les lignes, retourne une liste.
for ligne in f:Parcourt le fichier ligne par ligne, efficace en memoire.

Ecrire dans un fichier

ecriture.py
with open("sortie.txt", "w", encoding="utf-8") as f:
    f.write("Premiere ligne\n")
    f.write("Deuxieme ligne\n")
    f.writelines(["a\n", "b\n", "c\n"])

with sur plusieurs fichiers

copier.py
with open("source.txt") as entree, open("copie.txt", "w") as sortie:
    sortie.write(entree.read())

Verifier l'existence avant d'ouvrir

verification.py
from pathlib import Path

chemin = Path("donnees.txt")
if chemin.exists():
    contenu = chemin.read_text(encoding="utf-8")
else:
    print("Fichier introuvable")

pathlib est l'approche moderne recommandee pour manipuler des chemins et fichiers, plus lisible que l'ancien module os.path.

Creer son propre gestionnaire de contexte

contexte personnalise
class ChronoContexte:
    def __enter__(self):
        print("Debut")
        return self

    def __exit__(self, exc_type, exc_val, exc_tb):
        print("Fin (nettoyage garanti)")

with ChronoContexte():
    print("Travail en cours...")
