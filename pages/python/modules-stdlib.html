PY/Modules de la bibliotheque standard

La bibliotheque standard

Python est livre "piles incluses" : des dizaines de modules pretes a l'emploi couvrent la plupart des besoins courants sans installer quoi que ce soit.

Importer un module

syntaxes d'import
import math
print(math.sqrt(16))

from math import sqrt, pi
print(sqrt(16), pi)

import math as m
print(m.sqrt(16))

math — fonctions mathematiques

Fonction / constanteRole
math.sqrt(x)Racine carree.
math.floor(x) / math.ceil(x)Arrondi vers le bas / vers le haut.
math.pow(x, y)Puissance (retourne toujours un float).
math.log(x, base)Logarithme.
math.pi / math.eConstantes pi et e.
math.sin, cos, tanFonctions trigonometriques (en radians).
math.factorial(n)Factorielle de n.
math.gcd(a, b)Plus grand commun diviseur.

FonctionRole
