PY/Introduction

Introduction a Python

Python est un langage de programmation lisible, polyvalent, utilise aussi bien pour l'automatisation, le web, la science des donnees que l'intelligence artificielle. Sa syntaxe proche du langage naturel en fait un excellent premier langage de programmation.

Executer du code Python

Contrairement au HTML/CSS qui s'affichent dans un navigateur, Python s'execute : le code est lu ligne par ligne par un interpreteur qui produit un resultat (souvent affiche dans un terminal).

Bac a sable Python (via Pyodide) — cliquez sur Executer
Premiere execution. La premiere fois que vous cliquez sur "Executer" sur cette page, l'environnement Python (Pyodide) se telecharge dans votre navigateur : cela prend quelques secondes. Les executions suivantes sont instantanees.

Philosophie du langage

Python privilegie la lisibilite : il n'y a generalement qu'une seule facon evidente de faire les choses. Contrairement a JavaScript ou C, les blocs de code ne sont pas delimites par des accolades mais par l'indentation (les espaces en debut de ligne), qui n'est donc pas optionnelle.

indentation obligatoire
if 5 > 3:
    print("5 est plus grand")  # indente de 4 espaces
    print("toujours dans le bloc if")
print("revenu au niveau normal")

Comment utiliser cette reference

  • Syntaxe et variables — les bases pour stocker et nommer des donnees.
  • Types de donnees — nombres, texte, booleens, et leurs conversions.
  • Operateurs — arithmetique, comparaison, logique.
  • Conditions et boucles — controler le flux d'execution.
  • Fonctions — regrouper du code reutilisable.
  • Listes et tuples, dictionnaires et sets — les structures de donnees.
  • Fonctions sur les chaines — manipuler du texte.
  • Reference : fonctions integrees — la liste complete des fonctions natives.
  • Modules de la bibliotheque standard — les outils fournis avec Python.
  • Programmation orientee objet — classes et objets.
  • Exceptions et fichiers — gestion des erreurs et des entrees/sorties.
