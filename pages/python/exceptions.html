Exceptions et gestion des erreurs

Une exception est un evenement qui interrompt le flux normal d'execution. Python permet de la "capturer" pour eviter que le programme ne plante.

Exceptions courantes

ExceptionSe produit quand...
ValueErrorune valeur a le bon type mais une valeur invalide (int("abc")).
TypeErrorune operation est appliquee a un type incompatible ("a" + 5).
IndexErrorun index de liste/tuple est hors limites.
KeyErrorune cle de dictionnaire n'existe pas.
AttributeErrorun attribut/methode n'existe pas sur l'objet.
NameErrorune variable n'est pas definie.
ZeroDivisionErrorune division par zero est tentee.
FileNotFoundErrorun fichier a ouvrir n'existe pas.
ImportError / ModuleNotFoundErrorun module a importer n'existe pas.
StopIterationun iterateur n'a plus d'elements.
RecursionErrorune fonction recursive depasse la profondeur maximale.

Lever ses propres exceptions

raise et exceptions personnalisees
Bonne pratique. Attrapez toujours l'exception la plus specifique possible plutot qu'un except: generique — cela evite de masquer des bugs inattendus qui n'ont rien a voir avec le probleme anticipe.
