Fonctions

Une fonction regroupe du code reutilisable sous un nom. Elle peut recevoir des parametres et retourner un resultat.

Definir et appeler

def

Parametres par defaut et nommes

parametres avances

*args et **kwargs

arguments variables

Fonctions lambda

fonctions anonymes
carre = lambda x: x ** 2
print(carre(5))   # 25

# Utilite typique : comme argument d'une autre fonction
nombres = [5, 2, 8, 1]
print(sorted(nombres, key=lambda x: -x))  # tri decroissant

Portee des variables (scope)

Mot-cle / conceptRole
Variable localeDefinie dans une fonction, n'existe que pendant son execution.
Variable globaleDefinie au niveau du module, accessible partout en lecture.
globalA l'interieur d'une fonction, permet de modifier une variable globale.
nonlocalDans une fonction imbriquee, permet de modifier une variable de la fonction englobante.

Annotations de type (optionnelles)

type hints
def addition(a: int, b: int) -> int:
    return a + b

Ces annotations ne sont pas verifiees a l'execution par defaut, mais ameliorent la lisibilite et permettent a des outils (comme mypy) de detecter des erreurs de type avant l'execution.
