PY/Operateurs

Operateurs

Les operateurs permettent de combiner et comparer des valeurs.

Arithmetiques

OperateurRoleExemple
+Addition (ou concatenation de chaines/listes).3 + 4 -> 7
-Soustraction.7 - 2 -> 5
*Multiplication (ou repetition de chaines/listes)."ab" * 3 -> "ababab"
/Division, retourne toujours un float.7 / 2 -> 3.5
//Division entiere (arrondie vers le bas).7 // 2 -> 3
%Modulo, reste de la division.7 % 2 -> 1
**Puissance.2 ** 10 -> 1024

Comparaison

OperateurRole
==Egal (compare la valeur).
!=Different.
>Superieur strict.
<Inferieur strict.
>=Superieur ou egal.
<=Inferieur ou egal.
isCompare l'identite (meme objet en memoire), pas la valeur.
is notIdentite differente.

Logiques

OperateurRole
andVrai si les deux operandes sont vrais.
orVrai si au moins un operande est vrai.
notInverse la valeur booleenne.

Assignation composee

OperateurEquivalent
x += 1x = x + 1
x -= 1x = x - 1
x *= 2x = x * 2
x /= 2x = x / 2
x //= 2x = x // 2
x %= 2x = x % 2
x **= 2x = x ** 2

Appartenance et identite

in, is
== vs is. Utilisez == pour comparer des valeurs (le cas courant). Reservez is a la comparaison avec None : if x is None:.
