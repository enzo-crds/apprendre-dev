Méthodes speciales (dunder methods)

MethodeDeclenchee par
__init__(self, ...)Creation d'une instance : MaClasse(args).
__str__(self)print(objet) ou str(objet).
__repr__(self)Representation technique, affichee dans la console interactive.
__len__(self)len(objet).
__eq__(self, autre)objet == autre.
__lt__(self, autre)objet < autre (permet sorted() sur des objets personnalises).
__add__(self, autre)objet + autre.
__getitem__(self, cle)objet[cle].
__iter__(self)Rend l'objet iterable dans une boucle for.
__call__(self, ...)Permet d'appeler l'objet comme une fonction : objet().
__enter__ / __exit__Rend l'objet utilisable dans un bloc with (voir gestionnaires de contexte).

Classes abstraites et interfaces

Python n'a pas de mot-cle interface comme d'autres langages, mais le module abc (Abstract Base Classes) permet de definir des methodes que les classes filles doivent obligatoirement implementer.
