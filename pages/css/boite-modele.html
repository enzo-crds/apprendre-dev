CSS/Modele de boite (box model)

Le modele de boite

Chaque element HTML est represente par CSS comme une boite rectangulaire composee de quatre couches concentriques : contenu, padding, bordure, marge.

Les quatre couches

CoucheRole
contentLe contenu lui-meme (texte, image), dont la taille est fixee par width/height.
paddingEspace interieur entre le contenu et la bordure.
borderBordure visible tout autour du padding.
marginEspace exterieur, entre la bordure et les autres elements.
Visualiser le box model

box-sizing : le piege classique

Par defaut (box-sizing: content-box), width/height ne concernent que le contenu : padding et border s'ajoutent par-dessus, agrandissant la boite reelle. La plupart des developpeurs preferent border-box, ou width/height incluent le padding et la bordure.

reset courant
*, *::before, *::after {
  box-sizing: border-box;
}

Proprietes de dimension

ProprieteRole
width / heightLargeur / hauteur du contenu (ou de la boite entiere avec border-box).
min-width / min-heightTaille minimale, ne descend jamais en dessous meme si le contenu est petit.
max-width / max-heightTaille maximale, l'element ne grandit pas au-dela.
box-sizingcontent-box (defaut) ou border-box.
aspect-ratioForce un ratio largeur/hauteur (ex : 16/9).
overflowComportement du contenu qui deborde : visible, hidden, scroll, auto.
overflow-x / overflow-yControle le debordement axe par axe.

Notation abregee des marges et paddings

notation shorthand
margin: 10px;                     /* les 4 cotes */
margin: 10px 20px;                /* haut/bas 10px, gauche/droite 20px */
margin: 10px 20px 30px;           /* haut 10, cotes 20, bas 30 */
margin: 10px 20px 30px 40px;      /* haut droite bas gauche (sens horaire) */
margin-top: 10px;
margin-right: 20px;
margin-bottom: 30px;
margin-left: 40px;
margin: 0 auto;                    /* centre horizontalement un bloc de largeur fixe */

Ces memes notations (1, 2, 3 ou 4 valeurs) fonctionnent identiquement pour padding et border-width.

Bordures en detail

ProprieteRole
border-widthEpaisseur de la bordure.
border-stylesolid, dashed, dotted, double, groove, ridge, inset, outset, none.
border-colorCouleur de la bordure.
border-radiusArrondit les coins. Valeur unique ou 4 valeurs (coins).
border-top / -right / -bottom / -leftDefinit un seul cote (raccourci width+style+color).
outlineContour exterieur qui ne modifie pas la taille de la boite (utile pour le focus).
