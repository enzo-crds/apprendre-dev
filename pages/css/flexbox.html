CSS/Flexbox

Flexbox

Flexbox est un systeme de mise en page en une dimension (ligne OU colonne), ideal pour aligner et repartir de l'espace entre des elements dans un conteneur.

Activer Flexbox

display: flex

Proprietes du conteneur (parent)

ProprieteValeurs / role
displayflex (bloc) ou inline-flex.
flex-directionrow (defaut), row-reverse, column, column-reverse : l'axe principal.
flex-wrapnowrap (defaut, une seule ligne), wrap (retour a la ligne), wrap-reverse.
flex-flowRaccourci pour flex-direction + flex-wrap.
justify-contentAlignement sur l'axe principal : flex-start, flex-end, center, space-between, space-around, space-evenly.
align-itemsAlignement sur l'axe secondaire : stretch (defaut), flex-start, flex-end, center, baseline.
align-contentAlignement des lignes entre elles quand flex-wrap cree plusieurs lignes.
gap / row-gap / column-gapEspace entre les elements, sans marge sur les elements eux-memes.

Proprietes des items (enfants)

ProprieteRole
flex-growFacteur de croissance : combien un item grandit pour occuper l'espace libre (0 = ne grandit pas).
flex-shrinkFacteur de retrecissement quand l'espace manque (1 = retrecit normalement, 0 = ne retrecit jamais).
flex-basisTaille de depart avant repartition de l'espace libre.
flexRaccourci grow/shrink/basis. flex: 1 est tres courant (grandit et retrecit egalement).
align-selfEcrase align-items pour un seul item.
orderModifie l'ordre visuel sans toucher au HTML (defaut 0, peut etre negatif).
