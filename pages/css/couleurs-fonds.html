CSS/Couleurs et arriere-plans

Couleurs et arriere-plans

CSS propose plusieurs notations pour exprimer une couleur, et de nombreuses proprietes pour gerer les fonds.

Notations de couleur

NotationExempleDescription
Mot-clered, teal, coral147 noms de couleurs predefinis.
Hexadecimal#ff6600, #f60Rouge-vert-bleu en base 16, forme courte a 3 chiffres possible.
Hex + alpha#ff660080Deux chiffres supplementaires pour la transparence.
rgb()rgb(255 102 0)Rouge, vert, bleu de 0 a 255.
rgba()rgba(255 102 0 / 0.5)rgb + canal alpha (transparence) de 0 a 1.
hsl()hsl(24 100% 50%)Teinte (0-360), saturation, luminosite en pourcentage.
hsla()hsla(24 100% 50% / 0.5)hsl + transparence.
currentColorborder-color: currentColorReutilise la valeur de color de l'element.
transparentbackground: transparentTotalement transparent.
Notations de couleur

Proprietes d'arriere-plan

ProprieteRole
background-colorCouleur de fond.
background-imageImage ou degrade de fond (url() ou linear-gradient()).
background-repeatrepeat, no-repeat, repeat-x, repeat-y.
background-positionPosition de l'image : center, top left, 50% 50%, etc.
background-sizecover (remplit en gardant les proportions), contain (s'adapte sans deborder), ou taille precise.
background-attachmentscroll (defaut) ou fixed (l'image reste immobile au defilement).
background-clipZone ou le fond est peint : border-box, padding-box, content-box, text.
backgroundRaccourci combinant toutes les proprietes ci-dessus.

Degrades

Types de degrades
FonctionRole
linear-gradient()Degrade lineaire selon un angle ou une direction.
radial-gradient()Degrade circulaire ou elliptique depuis un centre.
conic-gradient()Degrade tournant autour d'un point (utile pour des roues de couleur).
repeating-linear-gradient()Degrade lineaire repete (motifs de rayures).

Effets visuels lies aux couleurs

ProprieteRole
opacityTransparence globale de l'element (0 a 1), affecte aussi le contenu.
box-shadowOmbre portee : decalage x, y, flou, etendue, couleur.
filterEffets graphiques : blur(), brightness(), contrast(), grayscale(), etc.
mix-blend-modeMode de fusion avec les elements en dessous (multiply, screen, overlay...).
