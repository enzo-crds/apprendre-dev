CSS/Variables (custom properties)

Variables CSS (custom properties)

Les variables CSS permettent de definir une valeur une seule fois et de la reutiliser partout, avec heritage et possibilite de redefinition contextuelle — impossible avec les preprocesseurs comme Sass qui ne calculent qu'a la compilation.

Declarer et utiliser une variable

Variables CSS

Syntaxe

ElementRole
--nom-variable: valeur;Declaration. Le prefixe -- est obligatoire.
var(--nom-variable)Utilisation de la variable.
var(--nom-variable, secours)Utilisation avec une valeur de secours si la variable n'est pas definie.
:rootSelecteur cible souvent utilise pour declarer des variables globales (portee sur tout le document).

Pourquoi c'est puissant

  • Heritage naturel — une variable redefinie sur un element s'applique a tous ses descendants, comme n'importe quelle propriete heritee.
  • Modifiable en JavaScript — element.style.setProperty('--couleur', 'red') permet de piloter le style depuis un script.
  • Themes dynamiques — changer une poignee de variables sur :root permet de basculer tout un theme (clair/sombre) sans dupliquer les regles.

Exemple : theme sombre avec variables

theme.css
:root {
  --fond: white;
  --texte: black;
}

[data-theme="sombre"] {
  --fond: #111;
  --texte: #eee;
}

body {
  background: var(--fond);
  color: var(--texte);
}

Il suffit ensuite de changer l'attribut data-theme sur <html> en JavaScript pour basculer instantanement toutes les couleurs du site.
