CSS/Fonctions CSS

Fonctions CSS

CSS n'est pas qu'une liste de proprietes statiques : de nombreuses fonctions permettent des calculs, des references dynamiques et des transformations.

Calcul et dimensionnement

FonctionRole
calc()Calcule une valeur en melangeant des unites : width: calc(100% - 40px).
min()Prend la plus petite valeur parmi celles fournies.
max()Prend la plus grande valeur parmi celles fournies.
clamp(min, valeur, max)Contraint une valeur fluide entre un minimum et un maximum. Tres utilise pour du texte responsive.
clamp() pour du texte fluide

Couleur

FonctionRole
rgb() / rgba()Couleur par composantes rouge, vert, bleu (+ alpha).
hsl() / hsla()Couleur par teinte, saturation, luminosite (+ alpha).
oklch()Espace de couleur moderne, perceptuellement uniforme.
color-mix()Melange deux couleurs selon une proportion.

Fond et formes

FonctionRole
url()Reference une ressource externe (image, police).
linear-gradient(), radial-gradient(), conic-gradient()Degrades de couleur.
clip-path()Decoupe l'element selon une forme (cercle, polygone).
shape-outsideDefinit une forme autour de laquelle le texte s'ecoule (avec float).

Transformation

FonctionRole
translate(), translateX(), translateY(), translate3d()Deplacement.
scale(), scaleX(), scaleY()Mise a l'echelle.
rotate(), rotateX(), rotateY(), rotateZ()Rotation.
skew(), skewX(), skewY()Inclinaison.
matrix()Transformation combinee via matrice 2D.

Filtres visuels

Fonction (utilisee dans filter)Role
blur()Flou gaussien.
brightness()Luminosite.
contrast()Contraste.
grayscale()Niveaux de gris.
saturate()Saturation des couleurs.
sepia()Effet sepia.
invert()Inversion des couleurs.
drop-shadow()Ombre portee suivant la forme reelle (utile pour PNG/SVG transparents).

Selection et repetition

FonctionRole
var()Recupere la valeur d'une variable CSS personnalisee.
attr()Recupere la valeur d'un attribut HTML (utilisable surtout avec content).
repeat()Repete un motif de colonnes/lignes en Grid.
minmax()Definit une taille de piste Grid entre un minimum et un maximum.
counter()Affiche la valeur d'un compteur CSS.
format()Precise le format d'une police dans @font-face.
