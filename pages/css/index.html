CSS/Introduction

Introduction au CSS

CSS (Cascading Style Sheets) controle l'apparence d'une page HTML : couleurs, tailles, positions, polices, animations. Sans CSS, une page web n'est que du texte brut structure.

Trois facons d'ajouter du CSS

1. Feuille externe (recommande)
<link rel="stylesheet" href="style.css">
2. Balise style dans le head
<style>
  p { color: navy; }
</style>
3. Style en ligne (a eviter sauf cas ponctuel)
<p style="color: navy;">Texte</p>

Anatomie d'une regle CSS

anatomie
selecteur {
  propriete: valeur;
  autre-propriete: autre-valeur;
}

Le selecteur designe les elements HTML a cibler. Le bloc entre accolades contient des declarations, chacune formee d'une propriete et d'une valeur separees par deux-points, terminee par un point-virgule.

La cascade et l'heritage

"Cascading" dans CSS fait reference a la maniere dont les regles se combinent quand plusieurs s'appliquent au meme element. Trois facteurs determinent quelle regle gagne :

  1. L'origine — les styles du navigateur, de l'auteur (vous), ou de l'utilisateur.
  2. La specificite — un ID (#mon-id) l'emporte sur une classe (.ma-classe), qui l'emporte sur un simple tag (p).
  3. L'ordre d'apparition — a specificite egale, la derniere regle declaree gagne.

Certaines proprietes (comme color ou font-family) sont heritees par les elements enfants automatiquement ; d'autres (comme margin ou border) ne le sont pas.

Comment utiliser cette reference

  • Syntaxe et selecteurs — cibler precisement des elements.
  • Modele de boite — comprendre margin, border, padding, content.
  • Couleurs et arriere-plans — toutes les facons de colorer.
  • Texte et typographie — polices, tailles, espacement.
  • Flexbox et Grid — les deux systemes de mise en page modernes.
  • Position et affichage — display, position, z-index.
  • Responsive — adapter le site a toutes les tailles d'ecran.
  • Transitions et animations — donner vie a l'interface.
  • Reference : toutes les proprietes, fonctions CSS, variables CSS — les listes completes.
