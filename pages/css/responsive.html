CSS/Responsive et media queries

Responsive et media queries

Le design responsive adapte l'apparence d'un site a la taille de l'ecran : mobile, tablette, ordinateur. Les media queries sont l'outil principal pour appliquer du CSS conditionnellement.

Syntaxe de base

media query
/* S'applique quand la largeur d'ecran est de 600px ou moins */
@media (max-width: 600px) {
  .conteneur {
    flex-direction: column;
  }
}

Approche mobile-first

La bonne pratique consiste a ecrire le CSS de base pour mobile, puis a ajouter des regles pour des ecrans plus grands avec min-width :

mobile-first
/* Styles de base : mobile */
.carte { width: 100%; }

/* Tablette et plus */
@media (min-width: 768px) {
  .carte { width: 50%; }
}

/* Ordinateur et plus */
@media (min-width: 1024px) {
  .carte { width: 33%; }
}

Points de rupture courants

CategorieLargeur indicative
Mobilejusqu'a 599px
Tablette600px a 899px
Petit ordinateur900px a 1199px
Grand ecran1200px et plus

Ces valeurs sont indicatives : le meilleur point de rupture est celui ou votre mise en page commence a casser visuellement, pas une valeur magique universelle.

Autres caracteristiques de media query

CaracteristiqueDetecte
orientationportrait ou landscape.
prefers-color-schemelight ou dark, selon le reglage systeme de l'utilisateur.
prefers-reduced-motionreduce, pour respecter les utilisateurs sensibles aux animations.
hoverhover: hover si l'appareil peut survoler (souris) vs hover: none (tactile).
aspect-ratioRatio largeur/hauteur du viewport.
print@media print cible specifiquement l'impression.
respecter les preferences utilisateur
@media (prefers-color-scheme: dark) {
  body { background: #111; color: #eee; }
}

@media (prefers-reduced-motion: reduce) {
  * { animation: none !important; }
}

Unites fluides sans media query

Certaines techniques evitent meme d'avoir besoin de media queries :

TechniqueExemple
clamp()font-size: clamp(1rem, 2vw, 2rem) — taille fluide entre un minimum et un maximum.
Grid auto-fitgrid-template-columns: repeat(auto-fit, minmax(200px, 1fr)) — colonnes qui s'adaptent seules.
Flexbox wrapflex-wrap: wrap — les elements passent a la ligne naturellement.
