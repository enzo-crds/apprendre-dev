CSS/Syntaxe et selecteurs

Syntaxe et selecteurs

Les selecteurs determinent quels elements HTML une regle CSS va styler. Il en existe pour tous les besoins : par type, classe, id, position dans le document, ou etat.

Selecteurs de base

SelecteurCibleExemple
*Tous les elements.* { margin: 0; }
elementToutes les balises de ce type.p { color: gray; }
.classeTous les elements ayant cette classe..carte { border: 1px solid; }
#idL'element unique ayant cet id.#header { height: 60px; }
a, bSelecteur groupe : a ET b (liste).h1, h2 { font-weight: bold; }

Selecteurs de combinaison

SelecteurCibleExemple
A BDescendant : B a n'importe quel niveau dans A.nav a { color: white; }
A > BEnfant direct : B, enfant immediat de A.ul > li { list-style: none; }
A + BFrere adjacent : B immediatement apres A.h2 + p { font-weight: bold; }
A ~ BFrere general : B apres A, meme parent.h2 ~ p { color: gray; }
Combinateurs

Selecteurs d'attribut

SelecteurCible
[attr]Possede l'attribut, quelle que soit sa valeur.
[attr="valeur"]L'attribut vaut exactement "valeur".
[attr~="valeur"]"valeur" est l'un des mots de l'attribut (separes par espaces).
[attr^="valeur"]L'attribut commence par "valeur".
[attr$="valeur"]L'attribut se termine par "valeur".
[attr*="valeur"]L'attribut contient "valeur" n'importe ou.
[attr="valeur" i]Comparaison insensible a la casse.

:focus-visibleFocus visible uniquement (clavier), pas au clic souris.
:activeElement en cours d'activation (clic maintenu).
:visitedLien deja visite.

Specificite : comment ca se calcule

La specificite se calcule en trois categories, du plus fort au plus faible :

  1. ID (#id) — poids fort
  2. Classes, attributs, pseudo-classes (.classe, [attr], :hover) — poids moyen
  3. Elements et pseudo-elements (div, ::before) — poids faible

Un style en ligne (attribut style) bat toutes les specificites de feuille de style, et !important bat tout le reste (a utiliser avec grande parcimonie).
